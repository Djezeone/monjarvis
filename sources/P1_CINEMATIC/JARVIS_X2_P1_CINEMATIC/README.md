# JARVIS X2 — P1 Cinematic Pack

P1 extends the P0 Visual Foundation with a free, code-rendered cinematic experience.

## Included
- real-time intro sequence
- scroll director
- Memory World 3D
- Physical World 3D
- section transition system
- cinematic CSS
- 3 fallback posters
- 3 procedural ambient sound beds
- storyboard
- optional generative media prompts
- Claude Code P1 integration guide
- Claude Code master prompt

## Principle
The high-end intro is rendered with WebGL + Motion instead of requiring a video file. A campaign video remains optional.

## Entry point
`components/cinematic/CinematicExperience.tsx`
