# JARVIS X2 — Vision & Positionnement

## Catégorie
**Personal Agent OS**

JARVIS X2 n’est ni un simple chatbot, ni une collection de dashboards. Il orchestre une continuité entre mémoire, raisonnement, outils, agents et environnement.

## Promesse
**Memory. Intelligence. Action. Presence.**

## Positionnement
- beau comme un produit de design numérique de premier plan ;
- calme comme un OS mature ;
- puissant comme un environnement agentique ;
- local par défaut ;
- transparent sur ce qu’il fait ;
- prudent sur ce qu’il est autorisé à faire.

## Signature UX
**Less interface. More presence.**

## Anti-patterns
- HUD permanent ;
- dizaines de widgets simultanés ;
- cyberpunk décoratif sans fonction ;
- dépendance à une API cloud pour la moindre commande ;
- microphone caché ;
- autonomie irréversible sans gate.
