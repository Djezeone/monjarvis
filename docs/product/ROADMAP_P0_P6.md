# Roadmap JARVIS X2

## P0 — Visual Foundation
Core, tokens, cursor, hands-free visuals, base UI.

## P1 — Cinematic
Landing, scroll director, Memory World, Physical World.

## P2 — Living Interface
Permissions, wake, STT/TTS adapters, state machine, approval shell.

## P3 — Intelligence Core
Hermes, Graphiti, jobs, tools, n8n, Home Assistant, browser boundary.

## P4 — Personalization & Self-Evolution
Identity persistent, routines, skill learning, preference model, proactive suggestions.

## P5 — Multi-Device Presence
Desktop/mobile/home nodes, realtime state sync, handoff, notifications.

## P6 — Production & Distribution
Installer, sandbox hardening, observability, update system, licensing, public beta.
