# Local-First Deployment

## Cible minimale
- app Next.js ;
- Hermes ;
- Ollama ;
- Graphiti ;
- Neo4j ;
- voice services ;
- n8n optionnel ;
- Home Assistant optionnel.

## Modes
### Local
Tout sur une machine/mini-PC.

### Hybrid
Core/memory locaux, services cloud ponctuels.

### Remote self-hosted
Serveur privé avec tunnel/VPN, jamais ports agent exposés sans contrôle d’accès.

## Objectif économique
Le chemin quotidien de base ne nécessite pas de facturation token.
