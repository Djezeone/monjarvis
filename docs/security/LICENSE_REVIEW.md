# License Review Checklist

Avant distribution commerciale :
- vérifier la licence de chaque dépendance à la version réellement embarquée ;
- ne pas supposer qu’un repo historiquement open source l’est encore sous la même licence ;
- openWakeWord : distinguer code et modèles préentraînés ;
- Piper : revoir les obligations GPL de la version retenue ;
- n8n : licence source-available/fair-code à traiter correctement ;
- Jarvis/isair : ne pas réutiliser commercialement sans audit ;
- assets générés : conserver provenance interne et conditions applicables ;
- MCP/plugins : inventorier chaque dépendance tierce.

Ce document est un checklist produit, pas un avis juridique.
