# Memory & Data Policy

## À mémoriser
- préférences explicites ;
- décisions ;
- procédures ;
- état important d’un projet ;
- personnes/relations utiles au contexte ;
- événements significatifs ;
- faits dont la validité peut évoluer.

## À ne pas mémoriser automatiquement
- chaque phrase ;
- secrets ;
- contenu micro brut ;
- données sensibles sans utilité durable ;
- conjectures présentées comme faits.

## Temporalité
Préserver provenance, date de validité et invalidation plutôt que d’écraser silencieusement l’historique.
