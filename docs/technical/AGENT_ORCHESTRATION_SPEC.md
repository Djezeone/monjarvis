# Agent Orchestration Specification

## Core
Hermes Agent reste l’orchestrateur principal.

## Rôles recommandés
- Research
- Builder
- Operator
- Analyst
- Security
- Home
- Scheduler
- Communication
- Memory
- Browser

## Délégation
Le Core délègue uniquement lorsqu’une sous-tâche est suffisamment autonome pour justifier un contexte séparé.

## UI
Afficher : statut, objectif, durée, résultat court.
Ne pas afficher : chaîne de pensée privée.
