# Automation & Physical Integration

## Hermes Jobs
Pour les tâches planifiées nécessitant raisonnement et contexte.

## n8n
Pour les workflows déterministes et les credentials d’intégration.

## Home Assistant
Pour l’état et l’automatisation du monde physique.

## Browser Worker
Pour la navigation agentique isolée.

## Routing
- raisonnement planifié → Hermes Job
- intégration déterministe → n8n
- maison / capteurs → Home Assistant
- web interactif → Browser Worker
- action sensible → Policy + Approval
