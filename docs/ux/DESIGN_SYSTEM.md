# Design System — JARVIS X2

## Direction
Contemporary digital product × installation art × ambient intelligence.

## Palette
- Void `#05070A`
- Mineral `#090D12`
- Graphite `#111820`
- Text `#EDF6FF`
- Muted `#8EA1B4`
- Cyan `#5DEBFF` — perception / activité
- Violet `#7867FF` — cognition / mémoire
- Gold `#D5A85A` — valeur exceptionnelle / confirmation
- Green `#63E6A5` — succès
- Red `#FF6D86` — intervention

## Motion
- Breath: lent, ambiant.
- React: 100–300 ms.
- Cinematic: 800 ms–2 s.
- Reduced motion: toutes les informations restent disponibles.

## 3D
Réserver la 3D au Core, Memory World, Agent Constellation et Physical World. Ne pas transformer chaque carte en objet 3D.

## Assets
Les fichiers `assets/manifests/assets-manifest.json` et `assets.ts` sont la source de vérité.
